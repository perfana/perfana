# Security Policy

## Reporting

If you discover a security issue, please report it privately via [GitHub Security Advisories](https://github.com/perfana/perfana/security/advisories/new).

Do **not** open a public issue for security concerns.

## What to include

- Description of the issue
- Steps to reproduce
- Impact assessment
- Suggested fix (if any)

## Response timeline

- **Acknowledgment**: within 3 business days
- **Initial assessment**: within 7 business days
- **Fix release**: depends on severity, typically within 30 days

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older   | No        |

## Scope

This policy covers the Perfana platform code in this repository. Third-party integrations (Grafana, Keycloak, etc.) should be reported to their respective maintainers.
