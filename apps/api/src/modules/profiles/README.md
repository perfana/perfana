# Profiles

Performance testing profiles with auto-configuration dashboards and benchmarks.

## Endpoints
| Method | Path | Purpose |
|--------|------|---------|
| GET | /profiles | List all profiles |
| GET | /profiles/:id | Get profile details |
| POST | /profiles | Create profile |
| PUT | /profiles/:id | Update profile |
| DELETE | /profiles/:id | Delete profile |
| GET | /profiles/:id/dashboards | Profile dashboards |
| GET | /profiles/:id/benchmarks | Profile benchmarks |
