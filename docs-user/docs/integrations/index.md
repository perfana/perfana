# Integrations

<p class="pf-lead">Connect the observability tools Perfana pulls metrics, logs, profiles, and traces from. Connect once at the organization level, then each system can use them.</p>

<div class="grid cards" markdown>

-   :material-chart-areaspline:{ .lg .middle } **Connect Grafana**

    ---

    The main metrics source (and InfluxDB/Prometheus through it).

    [:octicons-arrow-right-24: Connect Grafana](connect-grafana.md)

-   :material-speedometer:{ .lg .middle } **Connect Dynatrace**

    ---

    APM metrics for root-cause analysis.

    [:octicons-arrow-right-24: Connect Dynatrace](connect-dynatrace.md)

-   :material-fire:{ .lg .middle } **Connect Pyroscope**

    ---

    Continuous profiling data.

    [:octicons-arrow-right-24: Connect Pyroscope](connect-pyroscope.md)

-   :material-text-box-search-outline:{ .lg .middle } **Connect Splunk**

    ---

    Log events as metrics: error counts, exceptions by type.

    [:octicons-arrow-right-24: Connect Splunk](connect-splunk.md)

-   :material-text-box-multiple-outline:{ .lg .middle } **Connect Loki**

    ---

    Logs as metrics through Grafana's Loki datasource, plus log patterns and error lines per run.

    [:octicons-arrow-right-24: Connect Loki](connect-loki.md)

-   :material-book-open-variant:{ .lg .middle } **Connect Confluence**

    ---

    Publish generated reports as Confluence pages.

    [:octicons-arrow-right-24: Connect Confluence](connect-confluence.md)

-   :material-transit-connection-variant:{ .lg .middle } **Connect distributed tracing**

    ---

    Tempo, Jaeger, or Elastic APM traces.

    [:octicons-arrow-right-24: Connect tracing](connect-tracing.md)

</div>
